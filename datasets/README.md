# Datasets

## `mock/` — what the backend actually seeds from

Generated by `generate_vehicle_health_data.py` (stdlib only, no install needed) and consumed automatically by `backend/app/db/seed.py` on first startup:

| File | Schema highlights |
|---|---|
| `vehicles.json` | 8 vehicles - `vehicle_id`, `model`, `manufacture_year`, `firmware_version`, `mileage_km`, `charge_cycles` |
| `telemetry.json` | 60 time-series readings per vehicle - battery %/voltage/temp, ECU CPU/RAM/temp, coolant temp, oil pressure, CAN bus errors, GPS, fault codes, encryption status |

A handful of vehicles are deliberately scripted to trend toward each predictive-alert rule in their most recent readings (see `docs/Vehicle-Health-Dashboard-Plan.md` Steps 4-7), so the demo has something to show without any manual setup.

Regenerate anytime (e.g. after tweaking a schema or wanting different scripted scenarios):
```bash
python datasets/generate_vehicle_health_data.py
```

## Real public datasets (not downloaded — check license/login requirements yourself)

These aren't fetched automatically: several require a free account, and license terms vary by dataset. Useful if you want to swap the mock data for something real:

| Domain | Source | Notes |
|---|---|---|
| EV / battery health | [NASA Battery Dataset](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/) | Charge/discharge cycles to failure, widely used for RUL prediction |
| EV specs | [Kaggle: Electric Vehicle Specifications](https://www.kaggle.com/datasets/geoffnel/evs-one-electric-vehicle-dataset) | Range, battery capacity, efficiency by model |
| Predictive maintenance | [UCI: AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset) | Synthetic but realistic sensor + failure-mode data |
| Predictive maintenance | [Kaggle: Machine Predictive Maintenance Classification](https://www.kaggle.com/datasets/shivamb/machine-predictive-maintenance-classification) | Failure type classification |
| Vehicle recalls (US) | [NHTSA recallsByVehicle API](https://api.nhtsa.gov/recalls/recallsByVehicle) | Free, no auth - already wired in live, see `backend/app/services/external_apis.py` |
| EV charging locations | [Open Charge Map](https://openchargemap.org/) | Free key required - already wired in live, same file |
| Weather | [Open-Meteo](https://open-meteo.com/) | Free, no auth - already wired in live, same file |

**Note:** an earlier scaffold-era generator (`generate_mock_data.py`) and its output (`battery_health.json`, `fleet.json`, `predictive_maintenance.json`, `vehicle_telemetry.json`) were removed - nothing in the app read them; they predated the current MVP schema above.
