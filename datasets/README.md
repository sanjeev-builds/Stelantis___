# Datasets

## `mock/` — ready to use right now

Generated by `generate_mock_data.py` (stdlib only, no install needed). 120 realistic records each:

| File | Schema highlights |
|---|---|
| `vehicle_telemetry.json` | engine_temp, battery_voltage, rpm, speed, fuel_level, odometer, oil_pressure |
| `battery_health.json` | state_of_charge_pct, state_of_health_pct, charge_cycles, battery_temp_c |
| `predictive_maintenance.json` | component, wear_pct, predicted_failure_km, risk_level |
| `fleet.json` | vehicle_id, driver_id, status, lat/lng, daily_distance_km, idle_time_minutes |

Regenerate anytime, with more records or after tweaking a schema:
```bash
python datasets/generate_mock_data.py 500
```

Load straight into Postgres via the `/api/vehicles` POST endpoint, or read directly in a notebook/script for a quick demo without touching the DB.

## Real public datasets (not downloaded — check license/login requirements yourself)

These aren't fetched automatically: several require a free account, and license terms vary by dataset. If your actual problem statement needs real-world data, these are solid starting points:

| Domain | Source | Notes |
|---|---|---|
| EV / battery health | [NASA Battery Dataset](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/) | Charge/discharge cycles to failure, widely used for RUL prediction |
| EV specs | [Kaggle: Electric Vehicle Specifications](https://www.kaggle.com/datasets/geoffnel/evs-one-electric-vehicle-dataset) | Range, battery capacity, efficiency by model |
| Predictive maintenance | [UCI: AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset) | Synthetic but realistic sensor + failure-mode data |
| Predictive maintenance | [Kaggle: Machine Predictive Maintenance Classification](https://www.kaggle.com/datasets/shivamb/machine-predictive-maintenance-classification) | Failure type classification |
| Traffic | [US DOT / data.gov Traffic Volume datasets](https://catalog.data.gov/dataset?tags=traffic) | State/city level traffic counts |
| Road accidents | [UK DfT Road Safety Data](https://www.data.gov.uk/dataset/road-accidents-safety-data) | Long-running, detailed accident records |
| Weather | [NOAA Climate Data Online](https://www.ncdc.noaa.gov/cdo-web/) | Free API + bulk downloads, needs a token |
| Fleet / manufacturing defects | [Kaggle: Automotive Manufacturing Defects](https://www.kaggle.com/search?q=automotive+defect) | Search term — dataset availability varies, check licensing per result |

**Tip:** if the hackathon problem statement lands and you need one of these fast, grab the CSV and drop it in a new `datasets/real/` folder — keep the mock data as a fallback demo path in case downloads are slow on venue WiFi.
