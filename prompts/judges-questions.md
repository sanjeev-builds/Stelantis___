# Judge Q&A Prep Prompts

## Generate likely questions
```
We built [describe MVP] for [problem statement]. Generate the 8 hardest
questions a judge panel (mixing technical, business, and automotive-domain
judges) is likely to ask, and a one-sentence honest answer to each —
including questions that expose real weaknesses in what we built.
```

## Practice a hard question
```
A judge asks: "[paste question]". Here's what's actually true about our
build: [context]. Help me craft an honest, confident answer that doesn't
oversell what we didn't have time to build.
```
