# Presentation Prompts

## Turn the build into a pitch
```
Here's what we built: [describe features/screens]. Here's the problem
statement: [paste]. Using docs/presentation/pitch-kit.md as a template,
help me write a tight [3-minute/5-minute] pitch that leads with the
problem, shows the golden-path demo, and ends with impact + what's next.
```

## Tighten a pitch that's running long
```
Here's our current pitch script: [paste]. It's running [X minutes] over
the [Y minute] limit. Cut it down without losing the demo or the "why
this matters" — what goes first?
```
